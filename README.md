# OOP & SOLID – Practical Guide

## Overview

This repository is a step-by-step educational reference for learning Object-Oriented Programming (OOP) and SOLID principles using PHP only.

It starts from the junior level and gradually moves toward advanced concepts used in real-world, production-level applications.

The main goal is not only to understand theory, but to learn how to write clean, maintainable, scalable, and professional PHP code.

---

## Who Is This For?

This repository is designed for:

* Beginners learning programming
* Junior PHP developers
* Backend developers using PHP or Laravel
* Developers who understand basic PHP but struggle with OOP or SOLID

---

## What You Will Learn

### OOP Fundamentals

* What Object-Oriented Programming means
* Class vs Object
* Properties and Methods
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

These topics are explained from the ground up and build on each other step by step.

### SOLID Principles

* Single Responsibility Principle (SRP)
* Open/Closed Principle (OCP)
* Liskov Substitution Principle (LSP)
* Interface Segregation Principle (ISP)
* Dependency Inversion Principle (DIP)

Each principle is explained with clear PHP examples, including bad implementations and improved solutions.

## How to Use This Repository

1. Start from 01-oop-basics
2. Read each README carefully
3. Review the PHP examples provided
4. Compare bad implementations with improved ones
5. Apply the concepts in your own PHP projects

The order of the folders matters. Each section prepares you for the next one.

---

## Important Notes

* All examples in this repository are written in PHP only
* Concepts are explained gradually from junior to advanced level
* Focus on understanding the reasoning behind each concept, not memorizing code
